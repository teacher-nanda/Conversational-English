# American Empower — plan for the new student (starts Tuesday, Nov 10)

## 1. What I found in the material
- **Empower A1 = "Starter"**: true beginner (CEFR A1). Unit 1 starts with "Say your name and country" (I'm / you're / we're, countries, greetings). 12 units x 3 lessons (A, B, C). A = grammar + vocabulary, B = grammar + vocabulary + reading/listening, C = Everyday English (real-life situations: greeting, ordering in a cafe, shopping...) + writing. Every unit starts with a "Getting started" picture talk.
- **Empower A2 = "Elementary"**: 12 units x 4 lessons (A, B, C, D) + "Review and extension" + "Wordpower" + extra writing (D). Longer units, clear step up.
- Resources per level, in `_Books/American-Empower/`: Student's Book, Teacher's Book (answer keys, optional lead-ins, extra activities, drilling, culture notes), Workbook, class audio (with .vtt transcripts), workbook audio, documentary videos + video activity sheets (1 per unit), photocopiable worksheets (grammar, vocabulary, pronunciation), unit progress tests, mid-course and end-of-course tests, speaking tests.
- Note: the Student's Book and Workbook PDFs are scanned images (no text). The Teacher's Book is text, and the audio .vtt files give the audioscripts. I will read book pages visually when building each lesson.

## 2. Starting level and support (updated)
This is a general beginner course for many students; the first student (starts Nov 10) is just the first one to use it. It is NOT built around one person.
**Start with A1 Starter, Unit 1.** Everything on the slides is **English only**: no Portuguese or any other language, ever.
Beginners find it hard to build sentences, so the support is built into the course in English only:
- **Pictures, emojis and audio** show meaning (every new word and sentence has audio).
- **Sentence frames** ("I'm ___. I'm from ___.") and **word chips** to tap and build a sentence.
- **Listen and repeat first, create later:** short chunks, drilling (steps from the Teacher's Book), a "say it with me" step before each speaking task.
- **Clear model answers** shown before the student tries, then removed for the next round.
- **Welcome lesson (Lesson 0):** classroom language in English with pictures: "I don't understand.", "Can you repeat, please?", "Slowly, please.", "How do you spell it?" (the Empower audio has a Classroom Language folder).
- **Smaller steps:** one idea per block, checkpoints, and praise for evidence ("You just said a full sentence!").

## 4. How each Empower lesson should be built (same standards as AEF)
- Follow the Student's Book order exactly; everything from the book page is on the slides (you never use the book in class).
- Large text and very short instructions (this is a beginner).
- Audio on every listening and every new word/phrase (class audio from the book, wired by lesson).
- Every new word with a picture/emoji and a play button.
- Exercises in two columns, "Check answers" button, answers from the Teacher's Book / Workbook key.
- **Speaking is the main point**: after each exercise, one personal question using the language just learned (your idea about speaking time).
- Lessons split into **3 blocks with a checkpoint** (apply it in a mini-situation, quick check-in "what was hard?", next step), so a session can stop anywhere and still close well. (This comes from the Preply ideas; we decide after the conference, but it is especially useful in beginner lessons.)
- English only. Meaning is shown with pictures, emojis, audio and examples.
- Homework: workbook-exact for the language taught, plus online exercises; "Save Notes" PDF with the short header and button to the lesson.
- Extras from the Teacher's Book: optional lead-in, drilling, "extra activity" games and culture notes, used as interactive slides.
