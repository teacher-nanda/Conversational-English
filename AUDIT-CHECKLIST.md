# Empower lessons — Nanda's audit checklist (run on EVERY lesson before delivering)

Run: `python3 audit_emp.py <lesson index.html>` — it must print `AUDIT: OK`. Then look at the screenshots.

1. NEVER reduce font size. No `zoom`, no smaller inline font-size to make things fit. If it does not fit, split the slide or move things (e.g. audio player next to the instruction / wordbank).
2. Every new sentence goes on its own line (instructions, notes, dialogues, deck cards, answers).
3. Title sits right under the header dots — no wasted space at the top of the page.
4. Enough space between a wordbank and the questions (at least ~20px).
5. The teacher guides the live lesson: the student answers aloud (numbers 1, 2, 3 / letters a, b, c), never "Click…", "Write them here…". Homework slides are the only student-driven ones.
6. Instructions are friendly, not rude: "Let's…", questions ("Which words are I'm or we're?"). No bare orders like "Answer the questions about you."
7. Homework: never the same exercise as in class. If letters are scrambled, NO wordbank (it only gives the answer). Homework is self-contained, can use new vocabulary and spelling practice.
8. Options in exercises numbered (CSS numopts) so the student can say the number; vary the position of correct answers.
9. American English; 100% English; one-on-one wording (no pair/partner/class); no "Nanda" in activities ("me").
10. Only recorded book audio, never synthetic voices.
11. NEVER make an exercise with patterned answers (a, b, a, b / all the same / 1-2-3 in order) and NEVER put the answers in the same order as the wordbank (or reversed). Shuffle both the wordbank and the items. The audit script checks this.
12. NEVER show a wordbank AND scrambled letters on the same exercise. Typed-answer wordbanks: students can click a word to cross it out when used.
13. "Find it / match it" exercises: no hints (don't underline or mark the answers), don't make the student feel like a kid; show a small reference box (e.g. Short forms: We are – We're) and let the student search the text.
14. Instruction for a question slide is just the question + the answer line (e.g. "What other countries do you know in English?"); never narrate what the teacher will do ("I will write it down").
15. Never narrate what the teacher will do on the page ("I click each card", "I write it down", "We write it in our notes"). Instructions only say what the student does or the question itself. The audit script checks this.
16. Homework must be creative and practice what the lesson taught, with DIFFERENT exercise types per slide (situations/choose, word order, read-and-write, personal plan, YouTube...). Never three unscramble slides in a row.
17. Deliver: copy to outputs, commit force:true, verify md5 on the Mac (re-commit if the first copy is stale).
18. Never open instructions with "Let's ..." (only the bare instruction). Adult tone, nothing childish.
19. Follow the book's exercise order; theory slide, then its practice, before the next topic.
20. Number badges (1, 2, 3) on answer options ONLY when the options are images/emojis. Word or sentence answers have no badges; the student just says the answer.
21. Beginner checkpoints/speaking drills: only language already taught; the scenario never tells the student what to say; a "Stuck? Click here for options" reveal is available. Drills reuse the lesson conversations with the student's own name.
22. Audio player sits in a small box on the instruction row, not at the bottom of the slide.
23. Never split ONE exercise over several slides ("(1/2)", "part 2"). Put all items on one slide; if it is long, the slide scrolls and the wordbank (and its audio) stays visible in a sticky box (class sticky-bank). audit_emp.py flags "(n/m)" titles; overflow is only allowed on slides with a sticky-bank.
24. Checkpoint scenarios: interesting, built only from what was taught so far (this lesson and earlier lessons, e.g. Welcome help phrases), never telling the student what to answer, with a "Stuck? Click here for options" help that lists only the needed phrases.
25. Notes box standard (all American Empower lessons): no placeholder text; text sits exactly on the ruled lines (line-height 32px, lines scroll with the text); emoji stamp buttons next to the highlight colors (✅ Correct, ❌ Mistake, 🔊 Pronunciation, 📐 Grammar, 🏷️ Vocabulary, 💬 Expression, ⭐ Important, ❓ Question); light background, no outlines on the buttons; the Notes button shows an icon + "Notes" / "Close" (never raw code). Generated by theme.py.
26. Audio player standard: compact bar next to the instruction, with play/pause, time, the FULL seek line, volume and options visible; no "file to add" label once the audio file is wired.
27. Cover standard: "All courses" fixed at the bottom-left and "Homework" at the bottom-right of the lower navigation bar, visible only on the cover.
28. Each lesson has its own topic design (fonts, palette, icons, cover layout) set in theme.py (THEMES).
29. Check Answers / Reset always come AFTER the exercises, never before. On long slides the button row docks (sticky) at the bottom of the screen while scrolling. Run _Docs/audit_check.py on every lesson: it must report 0 slides with Check before exercises. normalize.py (called by theme.py) enforces this automatically. Scrolling is allowed on slides with a sticky wordbank or a docked Check row.
30. Check Answers / Reset: small buttons placed right after the exercises (no docking, no scrolling back up). Supersedes the docking idea in rule 29.
31. Ordering and matching exercises (answer is one number or letter): typed short blank placed INLINE on the same line as the sentence, never a dropdown and never on a new line. The sentences and the matching box must be visible together on one screen. normalize.py converts any single-character dropdown automatically.

32. Conversational course: from time to time (about every 2-3 slides of theory/practice, and at least once per lesson) include a SPEAKING ACTIVITY that practices what the slides teach - games, interaction, role-plays, "would you rather", storytelling chains, etc. Not only written exercises.
33. Repetitive "match each sentence to a meaning" lists must be presented in a more engaging way (e.g. click-to-pair game with color-locked matches, score, Reset). Fonts must be easy to read: no condensed/uppercase display fonts for titles (B2-2A uses Bitter + DM Sans).

34. Matching/click games: the student can match freely, wrong pairs allowed, click a matched item to undo; NO instant right/wrong feedback - answers (green/red + correct letter) appear only after Check Answers (placed after the exercise, small buttons). Both halves of a matching exercise must fit one screen.
35. Check Answers NEVER reveals the correct answers: it only marks right (green) and wrong (red) so the student can fix them and try again. Audit every exercise type (typed blanks, choices, matching) for any "show answer" behavior on Check; only a separate teacher-only key may show answers.
36. NO book references in anything the student sees (instructions, titles, notes labels): no "exercise 2a", "page", "unit", "in 3b", "Student Book". Instructions must be self-contained. Audit script: scan every slide text for \b\d[a-g]\b, "Unit N", "page", "exercise N", "Track N".
37. Keep vocabulary sets short: choose only the most common/useful items (about 6-7), not the full book list. Fill-in slides: wordbank at the top right after the instruction; no "Stuck?" help block.
38. Check Answers AND Show answers buttons always come AFTER the exercise (same small button row), never at the top or in a sticky top bar. Audit: python3 _Docs/audit_check.py (flags any check/show-answers button that has exercise items after it). Disguised answer buttons (e.g. "What does that tell you?") count as Show answers.
39. Pacing: never more than 2 vocabulary/pronunciation slides in a row without a speaking game or interaction; keep each vocabulary set to about 5-7 expressions total per lesson section (the rest goes to homework or is cut). Speaking games to rotate: story cards, two truths and a lie, role-play cards, would you rather, story chain.

40. Connection rule: every text or audio must connect to the teaching point. A language point (e.g. expressions with "get") is taught only because the listening/reading used many of them; take the items FROM that text/audio and refer back to them (with the line shown on the slide, rule 36 of self-containment still applies: the sentences must appear on the same slide). Audit: for every vocabulary/grammar section, list the source text/audio it comes from; flag sections with no connection.
41. CELTA-style teaching for every language point: (1) context from the text/audio, (2) MEANING check (concept questions / matching / situations), (3) PRONUNCIATION (stress, linking, weak forms - model, then repeat), (4) FORM (pattern/structure with examples), (5) controlled practice, (6) freer speaking practice. Audit each language section for the missing stages. Insert conversational activities between book exercises where they fit.
42. Every lesson's homework includes an AI-practice option (a ready-to-paste prompt for the student to practice the lesson language with an AI chat: role-play or conversation using the target language, with instructions to correct mistakes at the end).
